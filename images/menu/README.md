# Изображения меню

Каждая фотография хранится один раз. Несколько товаров могут ссылаться на один файл.
Чтобы заменить фотографию, положи новый WebP с тем же именем — пути в коде менять не нужно.
Имена описывают содержимое снимка; ассортимент на одном фото не является отдельным фото каждого товара.

| Файл | Содержимое |
| --- | --- |
| `flat-white.webp` | Флэт уайт, стеклянный стакан с карамельной пеной |
| `cappuccino.webp` | Капучино с молочной пеной |
| `latte.webp` | Латте с посыпкой |
| `raf.webp` | Раф в стеклянном стакане |
| `desserts-tiramisu-cheesecake.webp` | Ассорти десертов с тирамису и чизкейком |
| `combo-sandwich-coffee.webp` | Сэндвич, кофе и круассан |
| `desserts-croissant-cookie-brownie.webp` | Круассан, кукис, брауни и чизкейк |
| `matcha-and-cocoa.webp` | Матча и какао |
| `iced-latte-and-orange-coffee.webp` | Айс латте и апельсиновый кофе |
| `desserts-brownie-cheesecake.webp` | Ассорти брауни, чизкейка и выпечки |
| `lavender-coffee.webp` | Лавандовый кофе |
| `iced-latte-and-espresso.webp` | Айс латте и эспрессо |
| `croissant-and-two-coffees.webp` | Уникальный исходный снимок круассана и двух чашек; пока не подключён |
